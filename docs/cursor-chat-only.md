# Cursorを普通のAIチャットとして使う手順

## 一番シンプルな使い方

1. Cursorを起動する。
2. `Open Folder`や`Open Repository`は選ばない。
3. 空のウィンドウのままAIパネルを開く。
   - Mac: `Cmd+I`
   - Windows/Linux: `Ctrl+I`
4. モードを`Ask`にする。
5. 最初に次のように書いてから相談する。

```text
通常のAIチャットとして回答してください。
ファイル編集、コマンド実行、リポジトリ参照はしないでください。
```

## もしフォルダ指定を求められたら

- まずはキャンセル、閉じる、スキップを選ぶ。
- どうしても必要な場合だけ、実プロジェクトではなく空の相談用フォルダを作る。
  - 例: `cursor-chat-sandbox`
- GitHubリポジトリや本番アプリのフォルダは、相談だけのときは開かない。

## 安全設定

- 普段は`Ask`モードを使う。
- `Agent`モードは、ファイル編集やターミナル実行を任せたいときだけ使う。
- `Run Everything`は避け、コマンド実行は都度確認にする。
- `Browser Protection`、`File-Deletion Protection`、`External-File Protection`は有効にする。
- `Privacy Mode`を有効にする。

## 心配しなくてよいこと

- フォルダやリポジトリを開かない限り、その中のファイルを勝手に読んで変更することはありません。
- フォルダを開いただけで自動的にGitHubやVercelへ反映されるわけではありません。
- 影響が出るのは、主にAgentにファイル編集、コマンド実行、git操作、デプロイ操作を許可した場合です。

## おすすめ運用

- 雑談、調査、文章作成、アイデア出し: 空ウィンドウ + `Ask`
- アプリの修正、GitHub作業、Vercel作業: 対象リポジトリを開いて`Agent`
- 3Dプリンタ用データ相談: まず空ウィンドウ + `Ask`
- STLやOpenSCAD/CadQueryファイルを実際に作るときだけ、専用の3Dプリント用フォルダを開く。
