# ストア公開と法令メモ

本アプリは **成人向け（R18）作品の検索ビューア** です。公式アプリストアへの提出は、現行ガイドラインでは現実的ではありません。公開は **Web（必要ならホーム画面追加の PWA）** に限定します。

## 公式ストア（結論: 出さない）

| ストア | 判断 |
| --- | --- |
| Apple App Store | Guideline 1.1.4 によりポルノグラフィは禁止。WebView ラッパーや「ブラウザで開く」ネイティブ殻も拒絶される。 |
| Google Play | 性的に露骨なコンテンツのアプリは不可。 |
| Microsoft Store | ポルノグラフィ／露骨な性的コンテンツのアプリは不可。 |

PWA をストア経由で提出する案も、中身が成人向け検索である以上は同じ制限に当たります。ホーム画面への追加（Safari / Chrome の「ホーム画面に追加」）はストア審査を経ないため、Web 公開の延長として使えます。

## 今回の公開方針

- 公開チャネル: `https://fanza-nine.vercel.app`（Web）
- 任意: 対応ブラウザでのホーム画面追加（`app/manifest.ts`）
- ストア申請・審査提出は行わない

## 日本法・表示上の注意（実装方針）

- **18歳未満利用禁止**をヘッダー・年齢確認・規約で明示。年齢確認は自己申告（eKYC はしない）。
- **広告（アフィリエイト）**であることをボタン文言と `rel="sponsored"` で示す（ステルスマーケティング規制・景表法の不当表示を避ける）。
- 当サイトは **販売者ではない**。売買・配信の当事者は FANZA／権利者。特商法の通信販売者としての氏名住所掲載は、販売を行わないため「表記」ページで販売者不在を説明する。
- 動画ファイルはホスティングしない。API のメタデータと公式ページへの案内のみ。
- クイック検索から未成年を想起させる宣伝語（例: 「ロリ系」）は出さない。FANZA API の検索結果そのものは検閲しない。

このメモは法律助言ではありません。ストア方針や法令が変わった場合は再確認してください。
